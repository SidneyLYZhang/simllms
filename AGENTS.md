# simllms

Unified client for multiple LLM providers, shipped as both a cargo crate and a Python package.

## Agent skills

### Issue tracker

Issues and specs live as GitHub issues in `SidneyLYZhang/simllms`, driven by the `gh` CLI. The old `.scratch/` local-markdown convention is retired. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: `CONTEXT.md` plus `docs/adr/` at the repo root. See `docs/agents/domain.md`.
